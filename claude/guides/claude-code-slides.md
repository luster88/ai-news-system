# Claude Code Slides

## 2026-10-31

### Claude Code のスライド作成スキル5つ＋スキルなしで、同じ原稿から資料を作り比べた

Claude Codeで5つの異なるスライド作成スキル（Agent Skills）を使用し、スキルなしの場合も含めた6条件で同一原稿から資料を作成・比較。全条件で整ったスライドが生成されたが、PPTX出力可能なのはmckinsey-slidesとslidevのみ。consulting-pptx-skillは規約違反を自動検出・修正できる唯一の条件だった。スキルなしでも十分な品質が得られることが確認された。
