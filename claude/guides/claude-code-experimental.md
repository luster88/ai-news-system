### Claude Code 2.1.323のCode Mode入門、有効化と使えない条件

Claude Code 2.1.323で追加された実験的機能「Code Mode」の解説記事。JavaScriptを使って複数のツール呼び出しを1回のコード実行にまとめる仕組みで、環境変数CLAUDE_CODE_EXPERIMENTAL_CODE_MODE=1で有効化する。対話型のclaudeコマンドでのみ動作し、-pオプション、VS Code、クラウドセッションなどでは使用不可。npm latest版は2.1.325だがstable版は2.1.311のため、stable利用者は機能を使えない状態。
