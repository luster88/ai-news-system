### Skills と MCP の違い 「レシピ」と「キッチン」

Claude の拡張方法として、Skills と MCP の違いを解説。Skills は Claude が既存機能を効率的に使うための「レシピ」（手順書）であり、Progressive Disclosure 設計で必要時のみ読み込まれる。一方 MCP は外部ツールやデータソースに接続するための「キッチン」（共通プロトコル）で、新しい能力を追加する。Skills のインストール方法は Claude Code と Claude Desktop で異なるため注意が必要。
