## 2026-07-31

### GitHub ActionsのPR自動レビューを公式claude-code-actionで組む(APIキー課金なし)

GitHub ActionsでClaude Code Pro/Maxのサブスクリプショントークンを使い、APIキー課金なしでPR自動レビューを実装する手順を解説。公式claude-code-actionを使用し、インラインコメントとサマリコメントの両方を生成する。GITHUB_TOKENの明示的な指定、モデル選択、MCPツール権限設定、効果的なプロンプト設計（両方のコメント必須化、指摘ゼロ時の明示、既存コードとの突き合わせ）などの実装ノウハウを実測ベースで紹介。
