### Claude Code の 5 時間の枠が尽きる前に気づける。statusline に「使う速さ」を出す

Claude Codeの5時間の使用枠を効率的に管理するため、statuslineに使用率・経過時間・使用速度を表示する方法を解説。jqを使ったシェルスクリプトで実装し、使用速度が1.0を超えると赤色で警告表示。さらに枠に到達後も自動継続するautoContinueAtUsageLimitの設定についても紹介している。
