# Obsidian Integration

---

## 2026-07-28

### Claude Codeに毎回していた背景説明を、Obsidian連携10分でなくした

Claude Codeでの作業時に毎回行っていた背景説明を、Obsidian連携により自動化した事例。WSL2とWindows間のファイルシステム連携をbind mountで実現し、AIが作業完了時に自動で「現況ファイル」を更新する仕組みを構築。これにより次のセッションでは「現況ファイルを読んで続きをやって」の一言で作業を再開できるようになった。

- **ソース**: [Qiita claudecode](https://qiita.com/moname_ai/items/62f3dd740518fe111594)
- **重要度**: 6/10
- **タグ**: claude-code, setup, windows

## 2026-04-18

### Claude Code × Obsidian Vault で作る「何でも相談」プロジェクト ― フォルダ構成・CLAUDE.md・MCP設定まで全公開

Claude Codeで生成される.mdファイルの散乱問題を、Obsidian Vaultをプロジェクトに内包する構成で解決する実践的ガイド。CLAUDE.mdでファイル配置ルールを定義し、.claude/settings.jsonでモデル・推論レベルを固定、.mcp.jsonでEverythingプラグインを有効化する「何でも相談-pj」の全構成を公開。Mac/Windows間でポータブルに運用でき、デイリーノートによる文脈継続も実現。

- **ソース**: [Qiita claude](https://qiita.com/htani0817/items/0cb5e8f91fa64fb9ba8c)
- **重要度**: 7/10
- **タグ**: claude-code, setup, prompt
