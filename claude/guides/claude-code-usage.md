# Claude Code Usage

## 2026-10-21

### Claude Codeの「再開すると5時間枠を使う」警告は、Max 20xの42万トークンの会話でも出ませんでした

Claude Code v2.1.304で追加された「非アクティブな会話を再開すると5時間枠を大量消費する」警告機能について、Max 20xプランで42万トークンの会話を含む3本のテストを実施。いずれも警告は表示されず、プロンプトキャッシュが1時間で期限切れになったため会話内容をほぼ全て再構築していた。警告の発動条件となる「目立つ割合」や「非アクティブ期間」の具体的な基準は公式ドキュメントにも記載されていない。

## 2026-06-04

### 【番外編】「会話でマクロが直るツール、事務員がこんなの作ったの世界初だよね」── で返ってきた答えの話

Excel VBAとClaude Codeを組み合わせた「VBAマネージャー」開発者が、AIに類似ツールの存在を4ヶ月間問い続けた体験談。AIは「実物を見ないと正確に答えられない」「流暢に間違える」という特性を持ち、削除したはずの原稿を掘り起こすなど予期せぬ挙動も示した。開発者は「世界初」を主張したかったのではなく、逆に「誰かが同じことをやっているはず」と考え続けていた。
