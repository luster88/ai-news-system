## 2026-08-15

### Claude Desktop on Amazon Bedrock から Box へ接続してみた

Claude Desktop (Cowork) を Amazon Bedrock 経由で Box の MCP サーバー（mcp.box.com）に接続する手順を解説。Box Developer Account で OAuth 2.0 カスタムアプリを作成し、Claude Desktop からファイル検索やアップロードを自然言語で操作可能にする。Box 側のサーバーホスティングは不要で、無料アカウントで試せる実践的なセットアップガイド。
