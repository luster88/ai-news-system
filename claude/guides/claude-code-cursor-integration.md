# Claude Code Cursor Integration

---

## 2026-08-13

### Claude Code の続きを Cursor でやる — 履歴は継げるが、道具は別物

Cursor には Claude Code の会話履歴を Agents Window に取り込む機能があり、調査は Claude Code、差分確認や PR 作成は Cursor で行うといった使い分けが可能です。履歴本文と途中結論は引き継げますが、MCP やツールは Cursor 側のものに変わり、逆方向（Cursor → Claude Code）の取り込みや元スレッドへの追記はできません。Agents Window の Settings → Third-Party Imports で有効化でき、トグルが見当たらない場合は IDE ではなく Agents Window 側の設定を確認する必要があります。
