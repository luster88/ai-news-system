# Claude Certification

---

## 2026-08-11

### Claude certification 全冠した

Anthropic のパートナー企業向け Claude 認定資格4種（CCAR-F、CCAR-P、CCDV-F、CCAO-F）すべてに合格した体験記。2026年7月に新規公開された3資格を含む受験順序や難易度（CCDV-F < CCAR-F, CCAO-F < CCAR-P）、英語試験の難しさ、Udemy予想問題集の有効性などを記録。CCAR-Pは複数選択形式や上位レイヤの出題で最も難易度が高く、CCDV-Fは技術的内容で最も取り組みやすかったとの評価。
