# Image Recognition Limitations

---

## 2026-07-25

### Claude cannot read this font!

Mixfontが「Decoy Font」という特殊なフォントをリリース。人間には通常の文字が読めるが、Claude、ChatGPT、Geminiなどの画像認識AIには別のテキストとして認識される仕組み。通常の文字の上に細い輪郭のダミー文字を重ねることで、AIシステムを欺くことができる。コミュニティではAIジェイルブレイク手法として注目されている。
