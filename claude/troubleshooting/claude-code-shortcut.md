### Claude Code の 改行がShift+Enter でできない！

VSCodeでCLI版Claude Codeを使用する際、Shift+Enterで改行できず即送信されてしまう問題への対処法を解説。VSCode/Cursor以外のフォーク系エディタでは/terminal-setupが効かないため、keybindings.jsonに手動でショートカット設定を追加する必要がある。Ctrl+Jもパネル表示トグルに競合するため設定が必要。
