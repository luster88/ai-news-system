### Claude Code で "Auto-update failed" と "npm error code ENOTEMPTY" が出続けるときの直し方(残骸の削除とネイティブ版への移行)

Claude Codeで「Auto-update failed」と「npm error code ENOTEMPTY」が繰り返し発生する問題の解決方法を解説。npm版で更新時に残る一時フォルダ（.claude-code-*）を削除して再インストールすることで対処できるが、根本的な解決にはネイティブ版への移行が推奨される。公式ドキュメントとissue報告に基づく実践的なトラブルシューティング手順。
