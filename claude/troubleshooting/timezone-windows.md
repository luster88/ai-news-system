### Claude Codeを使っていて日時がずれて挿入されてしまうときの対処法

Claude Code で日付が UTC で挿入されてしまう問題への対処法。PowerShell のプロファイル設定で環境変数 TZ を Asia/Tokyo に設定し、CLAUDE.md に「日本時間（JST）を使用」とプロンプトで明示することで、正しい日本時間での日付挿入を実現する手順を解説。
