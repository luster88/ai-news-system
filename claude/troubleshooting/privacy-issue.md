### Claude Code の匿名運用でOSのユーザー名が録画に写った：探す名前を書かない検査

Claude Code デスクトップアプリで匿名運用中に、画面録画でOSのユーザー名などの個人情報が映り込んだ事例の報告。作業手順書に確認対象の文字列をそのまま記載していたことが原因で、3回の録画でそれぞれ問題が発生。最終的に検査手順を「探す名前を書かない」形式に改善した実例を詳述している。
