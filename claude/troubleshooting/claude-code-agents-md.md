### Claude CodeがAGENTS.mdを読み込まない理由と対処法

Claude CodeがAGENTS.mdファイルを読み込む機能について解説。新規作成直後の初回セッションでは反映されず、セッション再起動後に有効になる挙動を確認。AGENTS.mdは複数のAIコーディングツール共通の仕様で、CLAUDE.mdとの使い分けとして、ツール横断の方針はAGENTS.md、Claude Code固有ルールはCLAUDE.mdに書くことを推奨。
