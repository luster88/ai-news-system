### Claude Code 2.1.311入門、claude mcpで直ったのは表示だけだった

Claude Code 2.1.311で修正されたのは表示のみで、サブディレクトリから「claude mcp add」を実行した際のMCPサーバーの実際の保存先（リポジトリルート）は変わっていない。2.1.310と2.1.311を同一手順で検証し、エラーコード重複表示とプロジェクトパス表示の修正を確認。既存設定の登録し直しは不要。
