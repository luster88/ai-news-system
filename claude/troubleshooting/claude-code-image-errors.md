# Claude Code Image Errors

---

## 2026-11-05

### Claude Code で "Could not process image" "Request too large" "PDF too large" が出たときの直し方（画像は長辺 2000px 以下に）

Claude Code で画像や PDF を添付した際に「Could not process image」「Request too large」「PDF too large」エラーが発生する問題の解決方法を解説。基本的な対処法は Esc を 2 回押して画像添付前まで戻ることで、それが難しい場合は /compact、最終手段として /clear を使用。予防策として、画像を長辺 2000px 以下に縮小してから渡すことを推奨している。
