# Voice Mode Behavior

---

## 2026-07-30

### 【実測】同じ台本を3つの音声入力で喋ったら、「えっと」の扱いが3つとも違いました

Claude の voice mode で「えっと」「あの」などのつなぎ語（ひげ）が4個中3個消える挙動を実測。同じ台本を Claude Code のマイク、ChatGPT の音声入力で比較したところ、残り方が3つとも異なった。音声入力が「入力そのもの」か「後から作られた記録」かで、ひげの扱いが変わる可能性を指摘。2026年7月23日に public beta としてロールアウトされた voice mode のベータ段階での実測記録。
