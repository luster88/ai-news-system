# New Features

## 2026-11-11

### Claude Sheets・Whiteboards・Dataとは｜できること・使えるプラン・ベータの制限を整理

Claude の新機能として、チーム編集可能なスプレッドシート（Sheets）、ホワイトボード（Whiteboards）、ダッシュボード（Data）が追加された。Sheets と Whiteboards はベータ版で機能制限があり、Data は旧 Dashboards の正式版。Pro 以上のプランで利用可能だが、Free プランは対象外。会話から直接作成でき、チーム間で共同編集できるアーティファクトとして提供される。

- **ソース**: [AI Heartland](https://ai-heartland.com/explain/claude-sheets-whiteboards-data)
- **重要度**: 8/10
- **タグ**: 新機能, claude-console, release

## 2026-10-09

### Claude can now generate animated explainer videos and live data dashboards from text prompts

Anthropic が Claude に2つの新機能を追加しました。Dashboards は BigQuery や Snowflake などのデータソースと連携し、テキストプロンプトから自動更新されるダッシュボードを生成します。Motion はテキスト、図、画像からアニメーション解説動画を作成し、MP4 としてエクスポート可能です。Docs、Slides、Design はベータ版を卒業し、無料アカウントを含む全プランで利用可能になりました。Claude Design は12月14日までにメインアプリに統合される予定です。

- **ソース**: [The Decoder Claude](https://the-decoder.com/claude-can-now-generate-animated-explainer-videos-and-live-data-dashboards-from-text-prompts)
- **重要度**: 8/10
