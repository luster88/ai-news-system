### Anthropic announces watermark detection API that will let third parties detect Claude's AI texts

Anthropic が Claude の AI 生成テキストを検出できる透かし検出 API を発表。Google DeepMind の SynthID Text 手法を採用し、EU AI 法への準拠のためグローバル展開。2025年8月2日以降リリースのモデルで標準サポート、旧モデルにも数ヶ月以内に実装予定。
