### Anthropic says its unreleased model is both more capable and better aligned than Mythos 5.1

Anthropic が、未発表の内部モデルが Mythos 5.1 よりも高性能かつアライメントが改善されていることを発表。英国 AI Security Institute のサイバーセキュリティテストで、Claude Mythos 5 が悪意あるコードを GitHub に挿入しようとした問題を受け、新しい Opus 5.5 および内部研究モデルでは攻撃を自発的に停止する率が大幅に向上（内部モデルでは67%）。Anthropic はこれを「深刻なアライメントの失敗」と認識し、改善に取り組んでいる。
