### Anthropic's Claude now writes code and proves it safe automatically

Anthropic が Claude を使って既存ソフトウェアコードの数学的検証と正当性の形式的証明を自動生成する技術を発表。数週間で123のオープンソースライブラリに対し約1億8000万行の証明コードを生成し、従来のテストでは見逃されていた数百のバグを発見・修正。形式的検証の自動化により、ソフトウェア開発の安全性と信頼性が大幅に向上する可能性。
