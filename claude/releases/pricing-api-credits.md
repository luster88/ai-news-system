# Pricing Api Credits

---

## 2026-10-22

### Claude Maxに月$100のAPIクレジット——対話型Claude Codeには使えない、紐付けは変更不可

2026年10月7日からClaude MaxプランにAPI月額クレジットが付与される（Max 5xは$100、Max 20xは$200）。Claude API・Managed Agents・Agent SDK・Playgroundで使用可能だが、対話型Claude Codeには利用不可。Console組織との紐付けは変更不可で、毎月リセット・繰り越しなし。個人開発者にとって上限付きのAPI枠として有用だが、対象範囲と設定変更不可の制約に注意が必要。

## 2026-10-11

### Claude Max / Team プランで、API クレジットが毎月配布されるようになりました ── Max 20x は毎月 $200

Claude MaxおよびTeamプランの契約者に、毎月APIクレジットが付与されるようになりました。Max 5xは月$100、Max 20xは月$200、Teamは1席あたり$20-100（上限$500）です。Claude Consoleの組織をリンクすることで受け取れますが、繰り越しはできず、リンク後の組織変更も不可能です。チャットやClaude Codeの利用量とは別枠で、API呼び出しに使用できます。
