### MCP 2026-07-28アップデート徹底解説 - ステートレス化で何が変わり、何ができるようになったのか

2026年7月28日、AnthropicがMCP（Model Context Protocol）の5回目の大型アップデートを発表。最大の変更点は「ステートレス化」で、従来のセッション保持型プロトコルから1リクエスト完結型に移行。これによりMCPサーバーはサーバーレス・エッジ環境で動作可能になり、ロードバランサ配下での運用が容易に。Multi Round-Trip Requests（MRTR）により問い返し機能もステートレスで実現可能になった。MCPは月間4億ダウンロードを超え、950以上のサーバーが登録される業界標準プロトコルとして確立。
