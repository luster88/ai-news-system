# Claude Code Mods

---

## 2026-10-04

### Claude Code's new Mods system lets developers rewrite the AI coding tool from the inside

Anthropic が Claude Code に「Mods」システムをリリース。JavaScriptやTypeScriptでツール動作をカスタマイズできるミドルウェア機能で、UIパネル追加やツールコールのインターセプト、新規コマンドの追加が可能。公式プラグイン「You Should Know」も提供され、CLI、デスクトップアプリ、VS Code拡張で利用可能。Modsはユーザー権限で動作しサンドボックス化されていないため、信頼できるソースからのみインストールすることが推奨される。
