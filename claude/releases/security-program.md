### Anthropic gives more security teams access to Claude with fewer safety restrictions

Anthropic が Cyber Verification Program を大幅に拡大し、セキュリティ専門家により多くのアクセスを提供。脆弱性研究やマルウェア解析のために、Claude の安全フィルターを緩和した特別アクセスを3段階で提供。前身プログラムでは4ヶ月で12.9万件以上の脆弱性を発見し、AI により作業が数ヶ月〜数年分加速したと報告されている。
