# Organization Features

## 2026-09-18

### 【2026/9最新】Claudeのスキル・プラグインが組織に直接公開できるようになったので、触ってみた

Claude の Team/Enterprise プランで、メンバーが作成したスキル・プラグインを組織全体に直接共有できる新機能が追加されました。組織設定でレビューの要否を選択でき、「オープン」「レビューが必要」「オフ」の3段階で制御可能です。ただし Owner が提出した場合はレビュー設定に関わらず即座に公開される仕様となっており、運用時に注意が必要です。以前は個人所有のまま共有していましたが、今回から組織資産として管理できるようになりました。
