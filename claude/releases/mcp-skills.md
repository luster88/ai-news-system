### Skills over MCP とは｜サーバーがスキルを配る新拡張と Tasks・Elicitation を SDK で実測

AnthropicがMCPの新拡張「Skills over MCP」をパブリックベータで公開。MCPサーバーがツールと一緒に使い方の手順書（スキル）を配布できるようになり、クライアントは必要な時だけ読み込む。同時にTasks（長時間処理）とElicitation（途中確認）がGA、TypeScript SDK 2.4.0で実装可能。Claude/Claude CodeのPro・Max・Ultraで既定オン、Teamは管理者が有効化可能。
