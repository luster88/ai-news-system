### Anthropic opens Claude AI text detection to regulators, media, fact-checkers, and others

Anthropicは、Claudeの生成テキストに埋め込まれた電子透かしを検証できるAPIを、規制当局・メディア・ファクトチェッカーなど承認された組織に公開しました。EU AI法の要件に対応し、GoogleのSynthIDテキスト手法を基にした統計的検出可能なパターンを採用しています。透かしはユーザーデータを含まず品質に影響しないとされますが、一部の批判的意見では文章品質への懸念や透明性リスクが指摘されています。
