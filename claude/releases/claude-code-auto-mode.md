# Claude Code Auto Mode

---

## 2026-08-09

### Anthropic Flips Claude Code to Auto Mode by Default Aug 14, after finding AI blocks 80%+ dangerous queries while humans only 14%

Anthropicは8月14日、Claude Codeのデフォルト設定を自動モードに変更しました。1,053人の有料テスターを対象とした研究で、AIは危険なコマンドの89%をブロックした一方、人間による手動承認は13.6%しか検出できませんでした。50プロンプト後には人間の検出率は5%まで低下し、承認疲労が顕著でした。自動モードはTeam/Enterpriseユーザーのプルリクエスト数を25%増加させ、Anthropicは分類器が消費する追加トークンの課金を停止します。

### Anthropic is turning Claude Code’s auto mode on by default

Anthropicは8月14日から、Claude CodeのProプラン以上でautoモードをデフォルト設定にすると発表。autoモードでは破壊的・不可逆的な操作以外は人間の承認なしで実行され、テストでは手動レビュー（13.6%）よりも高い89%の有害操作検出率を記録。プロンプトインジェクション対策やカスタマイズ可能な拒否ルールなどの安全機能も追加された。
