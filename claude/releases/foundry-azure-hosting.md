## 2026-08-18

### FoundryのClaudeにWeb検索・MCPコネクタ等5機能、Hosted on Azure対応の実態

Microsoft Foundry の Claude モデルに、Structured outputs、Web search、Web fetch、MCP connector、Tool search の5機能が Hosted on Azure デプロイで利用可能になったと公式発表された。これにより、従来は Hosted on Anthropic 限定だったエージェント系機能を、プロンプトと補完を Azure 内に留めたまま使用できるようになる。ただし2026年8月18日時点で Anthropic 側の公式ドキュメントは「Hosted on Azure では非対応」の記述のままで、発表とドキュメントの食い違いが生じている。
