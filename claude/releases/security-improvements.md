### Opus 5 may have solved browser-based prompt injection, the biggest security flaw haunting AI agents

Anthropic の Opus 5 は、ブラウザベースのプロンプトインジェクション攻撃に対してほぼ完全な耐性を示しました。Auto Mode 有効時、129のテストシナリオで攻撃成功率0%を達成し、これは OpenAI が「完全解決は困難」と認めていた問題に対する大きな進展です。Gray Swan 社のテストでも、攻撃成功率が Opus 4.8 の 5.5% から Opus 5 では 2.0% に低下しました。この防御は、データスキャンと危険な動作のブロックという2層の防御システムによって実現されています。
