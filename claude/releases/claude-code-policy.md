### Anthropic cracks down on game cloning in Claude Code after wave of AI-built knockoffs

Anthropic が Claude Code で既存ゲームのクローン作成を禁止する措置を実施。Opus 5.5 のシステムプロンプトに2文が追加され、他者のゲームを複製できなくなった。この変更は、AI を使った大量のゲームクローン（Halo、GTA Vice City など）が作成された問題への対応。知的財産権侵害は利用規約違反となる。
