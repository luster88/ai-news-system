### 【2026/9/28】Claude Sonnet 5.5リリース——単価据え置きで実コスト3割減、ProプランのデフォルトはOpusに交代

2026年9月28日、Anthropic が Claude Sonnet 5.5 をリリース。トークン単価は $2/$10 per MTok で据え置きながら、30%以上の高速化とタスクあたり最大30%のコスト削減を実現。Terminal-Bench 4.0 で 10.3%→70.6% への大幅スコア向上など、コーディング・エージェント系ベンチマークで顕著な性能改善を達成。Claude Code では v2.1.284 で Sonnet 5.5 がデフォルトの Sonnet モデルに設定されたが、その直前の v2.1.280 で Pro・Team Standard プランのデフォルトが Sonnet から Opus に変更されており、Sonnet 5.5 は「明示的に Sonnet を選択した場合」のモデルという位置づけになっている。
