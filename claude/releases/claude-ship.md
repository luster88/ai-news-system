### Anthropic launches Claude Ship, letting AI agents review, fix, and approve code changes

Anthropic が Claude Ship を発表。AI エージェントがコードレビュー、修正、承認を自動化する新機能群。Code Review（一般提供済み）に加え、PR Steward と Claude Approvals の2つのベータ版エージェントを導入。特に Claude Approvals は、チームが設定したポリシーに基づいてコード変更を自動承認できる点が画期的。AI が大量のコードを生成する時代において、レビュー・承認のボトルネック解消を目指す。
