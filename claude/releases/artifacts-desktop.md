## 2026-11-25

### Anthropic turns Claude Artifacts into standalone desktop apps for macOS and Windows

Anthropic が Claude Artifacts を macOS と Windows のスタンドアロンデスクトップアプリとして展開できる機能をベータ版でリリース。チャットで Artifact を作成し、コードを書かずにドックに配置可能。OS API、コネクター、Claude 自体を利用でき、カスタムターミナルやファイルマネージャー、ビデオエディターなどの例が提供されている。無料アカウントでも利用可能で、Apple Developer アカウントがあればスタンドアロンアプリのビルドも可能。
