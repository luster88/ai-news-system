## 2026-10-30

### Usage and Cost Analytics API ベータ公開と旧API移行・リクエスト上限128MB拡大

Anthropicが Usage and Cost Analytics API をベータ公開し、旧APIをレガシー化しました。新APIでは組織のトークン使用量とコストを詳細に取得でき、部門別の費用配賦などに活用できます。また、Messages API と Token Counting API の最大リクエストサイズが32MBから128MBに拡大され、大きなファイルの処理が容易になりました。旧APIは引き続きサポートされますが、早めの移行計画が推奨されます。
