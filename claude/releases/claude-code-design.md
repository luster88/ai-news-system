## 2026-08-18

### Claude Code gets a /design command that lets developers create UI mockups right in the terminal

Anthropic が Claude Code に /design コマンドの早期プレビューをリリース。開発者はコードを書く前にターミナルや デスクトップアプリで UI モックアップを直接作成できるようになった。Claude は既存のコードベースを読み取り、現在の UI スタイルに合わせた複数のデザイン案を Artifacts として生成し、選択・編集後にビルドへ移行できる。claude update コマンドで試用可能。
