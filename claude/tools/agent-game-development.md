### Lattice: An isometric game kit for agents

Lattice は、AI エージェント向けに設計されたアイソメトリックゲーム開発キットです。TypeScript パッケージ、エージェント用スキル、プラグインで構成され、外部アセット不要で完全に決定論的なゲームを作成できます。Claude Code、Codex、Grok にプラグインをインストールし、/lattice コマンドでゲームアイデアを実装可能です。キット自体も Claude Code (Opus 5) で開発されています。
