### Orca Bots とは｜Slack で頼むと自分の Claude Code が直して PR を返す、仕組みと安全策

Orca v1.4.265で追加されたOrcaBotsは、Slack・GitHub・LinearからBotに依頼すると、自分のマシン上のClaude CodeやCodexが作業を実行し、PRと作業ツリーを返す機能。チャットで終わる通常のBotと異なり、実際の作業成果物を返す点が特徴。Bot実行は所有者権限で行われ、依頼可能なユーザーと権限モードで制御される。
