### AI エージェントの設定を、機能ごとに ON / OFF する CLI「llmtpl」をつくった

AI エージェントの機能を ON/OFF するための CLI ツール「llmtpl」が公開されました。Claude Code などで機能追加時に設定が複数箇所に散らばる問題を解決し、機能ごとのディレクトリ（バンドル）にまとめて設定ファイル 1 行で出し入れできます。複数リポジトリでの設定管理を効率化し、macOS/Linux に対応しています。
