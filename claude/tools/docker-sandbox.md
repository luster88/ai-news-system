### Docker Sandboxes入門 — AIコーディングエージェントを安全に「全自動」で回す実践ガイド

Docker Sandboxesは、AIコーディングエージェント（Claude Code、Codex等）を安全に「全自動モード」で動かすためのmicroVM隔離環境ツール。sbx CLIで操作し、エージェントがホストに影響を与えずsudo/docker等を自由に実行可能。ネットワークポリシーやシークレット管理機能も備え、ローカル・クラウド両対応。商用含めローカル利用は無料で、Docker Desktop不要で動作する。
