### Gridexとは｜データベース MCPサーバーを内蔵した7DB対応IDEのツール数を実装で数え直した

Gridexは、PostgreSQL・MySQL・SQLite・Redis・MongoDB・SQL Server・ClickHouseの7種類のデータベースに対応したネイティブIDEで、MCPサーバーを内蔵している。Apache-2.0ライセンスで公開されており、13個のMCPツール（Schema 6個・Read 3個・Write 4個）を提供し、接続ごとにlocked/read_only/read_writeの権限設定が可能。Claude DesktopやCursorから保存済み接続を利用でき、AIチャットはAnthropic・OpenAI・Ollamaの3プロバイダに対応している。
