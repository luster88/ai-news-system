# Open Slide Framework

---

## 2026-08-27

### open-slideとは｜Claude Codeでスライド作成する使い方とMarp・Slidevの違い

open-slideは、Claude Codeなどのエージェントがスライドを作成するためのReactベースのフレームワークです。MarpやSlidevと異なり、エージェントがコンテンツ（index.tsx）のみを記述し、ページ送り・発表者ビュー・書き出しなどの機能はフレームワーク側が提供します。1920×1080固定のキャンバスで絶対ピクセル指定を使い、HTML/PDF/PPTX形式での出力が可能で、npxコマンド一発で環境構築が完了します。MITライセンスのOSSとして2026年4月に公開され、既に6,899スターを獲得しています。
