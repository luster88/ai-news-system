### Claude Code Routerとは｜9種のAIコーディングエージェントを1つのローカル窓口に束ねる制御盤

Claude Code Router（CCR）は、Claude CodeやCodexなど9種類のAIコーディングエージェントを1つのローカルエンドポイント（127.0.0.1:3456）で一元管理できるモデルゲートウェイツール。複数のエージェントを併用する際に、それぞれ異なる設定ファイルや環境変数を書き分ける手間を解消し、プロバイダ・モデル・認証情報を一箇所で管理できる。OpenAI互換だけでなく、5種類のプロトコル方言（Anthropic Messages / OpenAI Chat Completions / Gemini generateContent等）に対応し、エージェントごとに専用の設定・起動処理を持つ実装になっている。MITライセンスでGitHub公開中（★36,263）で、最新版v3.0.17は2026年7月28日リリース。
