### GitHub Spec Kitとは？AIエージェントに「仕様」から実装させる新しい開発フローについて

GitHubが公開したAIエージェント向けの仕様駆動開発ツールキット「Spec Kit」について解説。バイブコーディングで起きる意図のズレや手戻りの課題に対し、仕様を先に確定させてから実装する開発フローを実現する。specify CLIとMarkdownテンプレート、スラッシュコマンド群で構成され、Claude Code、GitHub Copilot、Cursorなどに対応。constitution.md（原則）→spec.md（要求）→plan.md（技術計画）→tasks.md（実装タスク）という段階的なワークフローで、仕様書をGit管理しながら実装の一貫性を保つ。
