# Claude Code Gui

---

## 2026-10-05

### Claude Code に任せた作業を横で見て確かめる macOS アプリ「tanacode」1.0.0 をリリースしました

Claude Code（claude CLI）とIDEを統合したmacOS用アプリ「tanacode」1.0.0がリリースされました。複数セッションの並行管理、ファイル変更の可視化、コンテキスト圧縮の手動調整、ブラウザプレビュー統合、差分レビュー機能などを搭載し、Claude Codeの作業監視と確認を効率化します。既存のclaude CLIをそのまま使用するため、CLAUDE.mdやMCP設定もそのまま利用可能です。
