### AI エージェントの設定を、機能ごとに ON / OFF する CLI「llmtpl」をつくった

AI エージェントの機能追加/削除時に設定ファイルが散在する問題を解決する CLI ツール「llmtpl」の紹介。Claude Code などの設定をディレクトリ単位でバンドル化し、設定ファイルの 1 行で ON/OFF できる。複数リポジトリで設定を使い回す際に特に有効。
