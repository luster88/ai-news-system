### Claude Code ではなく Claude Desktop を使うメリット

Claude Desktop の Cowork 機能と Code 機能について解説。Code 機能は VSCode とは異なる AI 時代の IDE としてのポテンシャルを持ち、開発作業を画面内でシームレスに完結できる。Cowork 機能はローカルファイル操作が可能な Chat の拡張版で、グローバル設定や機能拡張を GUI で管理可能。両機能とも Agent SDK を内部で使用しているが、システムプロンプトやハーネスが異なるため動作に差がある。
