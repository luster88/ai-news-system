### 複数のClaude Codeを1画面に並べる、Claude Gridを自作しました

複数のClaude Codeを1画面にタイル状に並べて管理できる「Claude Grid」（OSSとして「CC Grid」公開）が開発されました。xterm.jsとnode-ptyを使用した本物のターミナルで、パネルごとの状態を色で表示、5分以上応答待ちのパネルに「要対応」ラベル表示、通知機能、Git情報とコンテキスト使用率の表示、配置の保存・復元などの機能を備えています。worktree連携による衝突回避や履歴検索も実装され、127.0.0.1からのアクセスに限定したセキュリティ設計となっています。
