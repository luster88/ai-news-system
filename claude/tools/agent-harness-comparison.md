### Fancy harnesses make coding agents more expensive but not better, study finds

中国の研究者が、コーディングエージェントのハーネス（Claude CodeやOpenCodeなど）を比較調査した結果、高度なハーネスはコストが3倍になるものの、性能向上はほぼノイズの範囲内であることが判明。SWE-bench Verifiedでの再実行による変動幅（最大6ポイント）が、ハーネス間の差異を上回ることが示された。研究では5つのモデルで3種類のハーネスをテストし、専用ツールや長いシステムプロンプトを持つ複雑なハーネスが必ずしも優れているわけではないことを実証した。
