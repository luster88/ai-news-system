## 2026-11-02

### Claude Codeに「進捗どう？」と聞くのをやめた ― 隣の画面で勝手に育つ"きょうのボード"

Claude Codeに進捗確認を繰り返す手間を解決するため、Claude自身がHTML形式の「きょうのボード」を自動更新する仕組みを開発。外部サーバー不要で、スキル機能とPythonスクリプトのみで構成。朝にボードを発行し、タスク完了時にClaude自身が書き換え、複数セッションの進捗を一元管理できる。MITライセンスでGitHub公開中。
