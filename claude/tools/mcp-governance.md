### MCP サーバーは、インストール時ではなく実行の瞬間に止める

Snyk の Evo Agentic Development Security (ADS) で MCP Governance が GA になり、MCP サーバーの利用を記録・ブロックできるようになった。約1万の開発環境から4,524種類の MCP サーバーが見つかり、12人に1人に高リスクの問題が確認された。MCP サーバーはマニフェストに記載されず開発者が即座にインストールするため、従来の AppSec では検出できない。コード内だけでなく開発者マシンでの検出が重要で、許可リストによる段階的な管理が推奨される。
