### Chromeに増えた「Claude」タブグループ45個を、自動で全部消した

Chrome ブラウザに蓄積した45個の「Claude」タブグループを、Agent Desktop（Vercel製のデスクトップ自動化ツール）と Claude Code を組み合わせて一括削除した事例。画面の直接指定では失敗したが、マウス操作モードで成功。削除前の内容確認を推奨。
