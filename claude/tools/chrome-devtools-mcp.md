### Chrome DevTools MCPとは｜使い方と既定29ツールの中身・Playwright MCPとの違い

Chrome DevTools MCPは、Chrome開発チームが公式に提供するMCPサーバーで、AIエージェントが実際に動作しているChromeのDevTools情報（コンソールエラー、ネットワークリクエスト、性能トレース等）を直接読み取れる。スクリーンショットではなく実測値を渡せるため、エラー原因の特定が容易になる。既定29ツール・23,254バイトだが、--slimオプションで3ツールまで削減可能。Puppeteer基盤で操作後の待機も自動処理される。
