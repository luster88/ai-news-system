### I got tired of checking whether Claude Code needs me. So I gave it a physical status light.

ユーザーが Claude Code の作業状態を物理的に確認できるよう、USB ステータスライトを統合した事例。別ラップトップで長時間タスクを実行中、作業中は赤点滅、入力待ちは赤点灯、アイドル時は緑点灯に設定。Kuando Busylight を hooks を使って接続し、画面を常時確認する必要をなくした実用的な工夫。
