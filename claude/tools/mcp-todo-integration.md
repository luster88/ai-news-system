# Mcp Todo Integration

---

## 2026-10-27

### Claude Code に「今日なにやる？」を聞ける ToDo を MCP で作って、4か月自社で回してみた

合同会社もちもつが開発した「こつこつ」は、Claude Code と連携するゴール起点の ToDo アプリで、MCP サーバーを通じて AI がタスク管理を支援する。タスクごとに「完了の基準」と「現状」を明確に定義し、AI が list_today、add_subtask、complete_subtask などのツールを使って段階的にタスクを進行・記録する。4か月間の運用で5,920件のタスクを管理し、AI が647件に着手した実績があり、MIT ライセンスで GitHub 公開されている。
