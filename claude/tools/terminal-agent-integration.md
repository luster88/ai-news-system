# Terminal Agent Integration

---

## 2026-08-02

### cmuxとは｜Codex・Claude Codeの通知をフック注入で束ねるGhostty製ターミナル

cmuxは、複数のAIコーディングエージェント（Claude Code、Codexなど）を並列実行する際の「どれが入力待ちか分からない」問題を解決するmacOS専用ターミナルアプリ。各エージェントの設定ファイルにフックを書き込んで状態と通知を取得し、ペインの枠色やサイドバーで視覚的に表示する。Ghosttyのレンダラを使用し、16種類のエージェントに対応。ターミナル側から本来見えない「プロセスの意味論」を、エージェント側からの情報供給で補う設計が特徴。
