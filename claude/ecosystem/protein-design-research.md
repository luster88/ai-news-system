### Anthropic says any lab can now let a language model agent run the whole protein design stack

Anthropic が Claude モデル（Mythos Preview と Opus 4.8）を使った創薬実験の結果を公開。タンパク質結合体（minibinder）のデノボ設計において、1,320デザイン中354が標的に結合し、成功率26.8%を達成。これは業界標準の10-15%を大きく上回る結果で、Claude が既存のオープンソースツールを自律的に操作してタンパク質設計パイプライン全体を実行できることを実証した。独立したレビューはまだ未実施。
