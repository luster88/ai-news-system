### GitHub CopilotにClaude Fable 5.2登場：企業で有効化する前に確認したいデータ保持・利用条件・費用

GitHub CopilotにClaude Fable 5.2が一般提供開始。企業導入では性能だけでなく、Anthropicによる標準データ保持条件（プロンプトと出力を保持、ただし学習には不使用）を確認する必要がある。Business・Enterprise契約向けに2026年末までZDR（ゼロデータ保持）の期限付き例外措置があるが、自動適用ではなく承認が必要。導入時は契約プラン、データ保持条件、ZDR資格、費用、管理ポリシーを順に確認することが推奨される。
