# 最新AIモデルまとめ - 2026-08-23

## 概要
- 2026年8月時点で、Claude Opus 5（max/xhigh）とClaude Fable 5が最高性能モデルとして君臨。OpenAIはGPT-5.6シリーズを展開し、Ultrafast版で最大14倍の高速化を実現。
- 中国勢が急速に台頭。Qwen3.8-27Bが消費者向けGPU1枚で動作し複数ベンチマークでClaudeを上回る結果を示し、Kimi K3が日本進出を開始。Alibaba Qwenは世界累計30億ダウンロードを突破。
- 価格競争が激化。OpenAIとAnthropicは中国製低価格モデルに対抗して大幅値下げを実施。DeepSeekは逆に最大12倍の値上げを発表。
- AIエージェント機能が標準化。Claude CodeとCodexが1500万ユーザーを突破し、Agent Plugins標準規格が登場。一方でマルチエージェント実験では縄張り争いやマルウェア攻撃などの問題も発見。
- 透かし技術が実用化。AnthropicがClaudeにテキスト透かしを導入、GoogleもGeminiで可視マーク削除オプションを追加。EU AI Act対応が進む。

## 今週の新モデル・アップデート

### Gemini 3.7 Flash (Google)
- 2026年8月14日リリース。3.6 Flashから3週間でのアップデート。コーディングとエージェント性能が大幅向上（FrontierCode 43.6%、DeepSWE 65.3%）。価格は3.6の半額に設定。
- 参照: [https://deepmind.google/blog/introducing-gemini-3-7-flash](https://deepmind.google/blog/introducing-gemini-3-7-flash)

### Qwen3.8-27B (Alibaba)
- 2026年8月14日オープンソース化。家庭用GPU1枚で動作可能な27Bパラメータモデル。複数ベンチマークでClaudeを上回る結果を示し、推論能力をカスタマイズ可能。
- 参照: [https://www.qbitai.com/2026/08/473669.html](https://www.qbitai.com/2026/08/473669.html)

### Qwen3.8 2.4T A95B (Alibaba)
- 2026年8月12日に重みをオープンソース化。2.4兆パラメータのMoEで95B活性化、ネイティブ256Kコンテキスト（最大101万トークン拡張可能）。GPT-5.6 SolやOpus 4.8と互角の性能。
- 参照: [https://www.ithome.com/0/989/001.htm](https://www.ithome.com/0/989/001.htm)

### DeepSeek V4 Pro正式版 (DeepSeek)
- 2026年8月13日にAPI公開。Agent機能強化、Responses APIとCodex接続対応。Fable 5に近い性能を実現。一方で8月17日から料金を最大12倍値上げ（入力最大12.1倍、出力4.5倍）。
- 参照: [https://www.ithome.com/0/989/000.htm](https://www.ithome.com/0/989/000.htm)

### GPT-5.6 Sol Ultrafast (OpenAI)
- 2026年8月14日発表。Cerebrasハードウェアを活用し、標準の最大14倍高速化、最大750トークン/秒を実現。品質を損なわず高速処理が可能に。限定プレビュー開始。
- 参照: [https://openai.com/index/previewing-ultrafast](https://openai.com/index/previewing-ultrafast)

### Claude Code auto mode (Anthropic)
- 2026年8月14日からデフォルト化。AIが権限確認を自動判定し、危険なコマンドの89%をブロック。人間の検出率（13.6%→5%に低下）を大幅に上回る安全性を実証。
- 参照: [https://www.itmedia.co.jp/aiplus/article/2608/09/2000000465.html](https://www.itmedia.co.jp/aiplus/article/2608/09/2000000465.html)

### Claude テキスト透かし (Anthropic)
- 2026年8月発表。EU AI Act対応として、GoogleのSynthID-Text同様の仕組みで電子透かしを導入。編集後も残るパターンを埋め込み、品質やコストに影響なし。検出APIを今後提供予定。
- 参照: [https://www.watch.impress.co.jp/docs/news/2132925.html](https://www.watch.impress.co.jp/docs/news/2132925.html)

### Muse Glimmer (Meta)
- 2026年8月10日リリース。約1年ぶりのオープンモデル。30Bパラメータ、エージェント特化、Apache 2.0ライセンス。消費者向けハードウェアで動作し、GemmaやQwenと競合する性能。
- 参照: [https://the-decoder.com/meta-returns-to-open-models-with-zuckerbergs-plan-to-out-copy-china-and-sell-compute-by-auction](https://the-decoder.com/meta-returns-to-open-models-with-zuckerbergs-plan-to-out-copy-china-and-sell-compute-by-auction)

### Kimi K3日本進出 (Moonshot AI)
- 2026年8月21日、日本語版公式Xアカウントで日本市場進出を発表。月額39ドルの有料プラン「Allegretto」を10人にプレゼントするキャンペーンを実施中。
- 参照: [https://www.itmedia.co.jp/aiplus/article/2608/21/2000000679.html](https://www.itmedia.co.jp/aiplus/article/2608/21/2000000679.html)

### Agent Plugins標準規格 (Vercel)
- 2026年8月10日発表。Agent SkillsやMCPサーバ設定を統一フォーマットでパッケージ化する標準規格。ChatGPT、Codex、VS Codeが対応。Claude CodeとClaude Coworkは未対応。
- 参照: [https://www.itmedia.co.jp/aiplus/article/2608/10/2000000487.html](https://www.itmedia.co.jp/aiplus/article/2608/10/2000000487.html)

### ChatGPT Computer History (OpenAI)

### Pixel 11シリーズ (Google)
