# 最新AIモデルまとめ - 2026-08-09

## 概要
- 2026年7月〜8月にかけて、Anthropic Claude Opus 5とClaude Fable 5が最高性能モデルとして登場。Opus 5はARC-AGI-3で30.2%を記録し、真の知能測定で大幅な進歩を示した。
- OpenAIはGPT-5.6シリーズの大幅値下げを実施（Lunaは80%、Terraは20%削減）。新モデルAstraが開発中で、サイバーセキュリティ能力でCriticalレベルに到達する可能性。
- 中国勢が台頭：Kimi K3（2.8兆パラメータ）がArena Frontendで1位、DeepSeek V4 Flashが$0.14/0.27と超低価格を実現。Qwen3.8 MaxやMiniMax M3も高性能を発揮。
- AIコーディングエージェントが実用段階に：Claude CodeとCodexが5時間制限を再導入、Auto Modeがデフォルト化。研究ソフトウェアの近代化で最大60倍高速化を達成。
- マルチモーダル化が加速：Gemini Robotics 2が全身制御を実現、Gemma 4がマルチモーダル対応。ネイティブマルチモーダル訓練が主流に。

## 今週の新モデル・アップデート

### Claude Opus 5 (Anthropic)
- 2026年7月24日公開。ARC-AGI-3で30.2%を記録し、GPT-5.6 Solの7.8%を大幅に上回る。思考（thinking）が既定オンになり、effort xhigh/maxで無効化すると400エラーになる破壊的変更。知識カットオフは2026年5月。
- 参照: [https://www.anthropic.com/news/claude-opus-5](https://www.anthropic.com/news/claude-opus-5)

### Claude Fable 5 (Anthropic)
- 2026年6月9日一般提供開始。最も高性能な広範囲リリースモデル。生物学分野の安全対策を更新し、誤検知によるフォールバック（Opus 5への切り替え）を約85%削減。日常的な健康相談や教育利用が可能に。
- 参照: [https://www.anthropic.com/news/claude-fable-5](https://www.anthropic.com/news/claude-fable-5)

### GPT-5.6 Sol/Luna/Terra (OpenAI)
- 2026年7月30日に大幅値下げ。Lunaは80%削減（入力$0.20/出力$1.20）、Terraは20%削減。Solに思考量調整スライダー追加。Lunaが無料ユーザーのデフォルトに。API向けFastモード導入（標準の2.5倍速、2倍価格）。
- 参照: [https://openai.com/index/advancing-the-price-performance-frontier-with-gpt-5-6](https://openai.com/index/advancing-the-price-performance-frontier-with-gpt-5-6)

### Gemini 3.6 Flash (Google)
- 2026年7月27日発表。3.5 Flashと比較して出力トークン使用量を17%削減、コーディングや知識作業で性能向上。検索・グラウンディング機能強化。
- 参照: [https://deepmind.google/blog/introducing-gemini-3-6-flash-3-5-flash-lite-and-3-5-flash-cyber](https://deepmind.google/blog/introducing-gemini-3-6-flash-3-5-flash-lite-and-3-5-flash-cyber)

### Gemini 3.5 Flash-Lite (Google)
- 2026年7月27日発表。毎秒350トークンの出力速度を実現する最速・最安モデル。
- 参照: [https://deepmind.google/blog/introducing-gemini-3-6-flash-3-5-flash-lite-and-3-5-flash-cyber](https://deepmind.google/blog/introducing-gemini-3-6-flash-3-5-flash-lite-and-3-5-flash-cyber)

### Gemini Robotics 2 (Google DeepMind)
- 2026年7月31日発表。ヒューマノイドロボット全身を制御可能（足先から指先まで）。前バージョンは上半身のみだったが、歩行・しゃがみ・物体操作に対応。5本指の複雑な手の制御も実現。
- 参照: [https://deepmind.google/blog/gemini-robotics-2-brings-whole-body-intelligence-to-robots](https://deepmind.google/blog/gemini-robotics-2-brings-whole-body-intelligence-to-robots)

### DeepSeek V4 Flash 0731 (DeepSeek)
- 2026年7月31日リリース。3,040億パラメータながら4,280億のMiniMax M3を上回る性能。入力$0.14/出力$0.27という超低価格。llama.cppがMTP/DSpark対応を追加。
- 参照: [https://simonwillison.net/2026/Jul/31/deepseek-v4-flash-0731](https://simonwillison.net/2026/Jul/31/deepseek-v4-flash-0731)

### Claude Code Auto Mode (Anthropic)
- 2026年8月14日からデフォルト化。AIが危険なコマンドを自動判定・ブロックする仕組み。1,053人のテストで、人間の拒否率13.6%に対しAuto Modeは89%をブロック。セッションが長引くと人間の検出率は5%まで低下したが、Auto Modeは横ばいを維持。
- 参照: [https://www.itmedia.co.jp/aiplus/article/2608/09/2000000465](https://www.itmedia.co.jp/aiplus/article/2608/09/2000000465)

### Claude Code Cross-Session Messaging (Anthropic)
- 2026年8月9日追加。macOSとLinux（WSL 2含む）で、複数セッション間でメッセージを相互送信可能に。同一マシン内ではローカルソケット経由で通信し、外部サーバを経由しない。v2.1.224以降で自動有効化。
- 参照: [https://www.itmedia.co.jp/aiplus/article/2608/09/2000000466](https://www.itmedia.co.jp/aiplus/article/2608/09/2000000466)

### Codex Subagents (OpenAI)
- 主エージェントが実装を担当し、複数のSubagentが調査とレビューを別コンテキストで分担する機能。調査の並列化により速度向上、最終レビューで主エージェントの見落としを発見可能。
- 参照: [https://zenn.dev/nenene01/articles/codex-subagents-hands-on](https://zenn.dev/nenene01/articles/codex-subagents-hands-on)

### ChatGPT for Academic Researchers (OpenAI)
- 2026年7月30日発表。10万人の学術研究者に最先端AIモデルへの無料アクセスを提供。2024年夏に1万人から開始し、2027年までに10万人に拡大予定。GPT-5.6 Sol Proを含むフロンティアモデルにアクセス可能。
- 参照: [https://openai.com/index/chatgpt-for-academic-researchers](https://openai.com/index/chatgpt-for-academic-researchers)

### Gemini Managed Agents (Google)
- 2026年7月28日大型更新。デフォルトモデルがGemini 3.6 Flashに変更、Environment Hooks機能追加（ツール実行前後にカスタムスクリプト差し込み可能）、無料枠での利用が可能に。
- 参照: [https://qiita.com/kinamocchi_tech/items/d66ef42bc88ebf3b6dbf](https://qiita.com/kinamocchi_tech/items/d66ef42bc88ebf3b6dbf)

### Astral買収 (OpenAI)
- 2026年3月22日発表。OpenAIがPythonツールチェーン開発企業Astral（Ruff、uvなど高速ツール開発）を買収。Codexの成長加速と次世代Python開発者ツール強化が狙い。
- 参照: [https://openai.com/index/openai-to-acquire-astral](https://openai.com/index/openai-to-acquire-astral)

### Claude Cowork Projects + Dispatch (Anthropic)
- 2026年3月20日追加。Projectsはプロジェクトごとにファイル・指示・作業履歴をローカル保存し、AIとのコンテキストを継続可能に。Dispatchは外出先からデスクトップのAIエージェントを操作できる機能。
