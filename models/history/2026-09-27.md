# 最新AIモデルまとめ - 2026-09-27

## 概要
- 2026年9月時点で、Anthropic Claude Opus 5.5とClaude Fable 5.1が最高性能を維持。OpenAI GPT-6 Astra、SpaceXAI Grok 4.7が競合。
- Claude Opus 5.5は9月22日リリース。Fable 5.1並みの性能を40%低コストで実現し、エージェント・コーディングタスクで大幅向上。
- OpenAIは9月23日にGPT-6 Sol/Lunaを発表。前世代から50%のコスト削減を実現し、Solはコーディング向け、Lunaは軽量タスク向け。
- Google Gemini 3.8 Flash/Flash-Lite TTSが音声合成で登場。自然言語で声を生成でき、130言語対応。Gemini 3.8 Live with Live Avatarも企業向けに提供開始。
- AIエージェント分野が急成長。Claude Code、Codex、Gemini CLIなどのコーディングエージェントが実用化され、ハーネスエンジニアリングやMCP統合が進展。

## 今週の新モデル・アップデート

### Claude Opus 5.5 (Anthropic)
- 2026年9月22日リリース。Fable 5.1と同等の性能をOpus 5より40%低コストで実現。68万行のコード移行を1日未満で完了。サイバーセキュリティ面で強化され、危険な挙動が85%減少。
- 参照: [https://www.anthropic.com/claude-opus-5-5](https://www.anthropic.com/claude-opus-5-5)

### GPT-6 Sol / Luna (OpenAI)
- 2026年9月22日発表。Solはコーディング向け、Lunaは軽量タスク向け。API料金はGPT-5.6世代から50%削減。Solは入力$2/出力$10、Lunaは入力$0.10/出力$0.50。
- 参照: [https://openai.com/index/introducing-gpt-5-4-mini-and-nano](https://openai.com/index/introducing-gpt-5-4-mini-and-nano)

### Grok 4.7 (SpaceXAI)
- 2026年9月22日公開。処理速度2倍、価格半額を実現。API料金は入力$2/出力$6。CursorBench 4.0でGPT-5.6 SolやFable 5.1と競合。EEBenchでは64%と両者を上回る。
- 参照: [https://www.watch.impress.co.jp/docs/news/2142588.html](https://www.watch.impress.co.jp/docs/news/2142588.html)

### Gemini 3.8 Flash TTS / Flash-Lite TTS (Google)
- 2026年9月24日発表。自然言語で役柄・アクセント・声質を指定してゼロから声を生成。30秒の音声サンプルで声を再現可能。130言語対応。台詞ごとの演技指導、笑い声等の非言語表現挿入が可能。
- 参照: [https://www.itmedia.co.jp/news/article/2609/24/2000001703.html](https://www.itmedia.co.jp/news/article/2609/24/2000001703.html)

### Gemini 3.8 Live with Live Avatar (Google)
- 2026年9月24日企業向けに一般提供開始。写真1枚から表情豊かに話すアバターを生成。97言語対応。会話中に非同期でツールを実行可能。なりすまし防止のため電子透かし「SynthID」を埋め込む。
- 参照: [https://www.itmedia.co.jp/news/article/2609/25/2000001730.html](https://www.itmedia.co.jp/news/article/2609/25/2000001730.html)

### Qwen-Image-2.1 (Alibaba)
- 7Bパラメータの軽量アーキテクチャ。画像生成と編集を統合した単一モデル。RGBA透過レイヤーのネイティブサポート、最大10枚の参照画像を用いた高精度な局所編集が可能。
- 参照: [https://www.reddit.com/r/LocalLLaMA/comments/1wlgrft/qwenimage21_released](https://www.reddit.com/r/LocalLLaMA/comments/1wlgrft/qwenimage21_released)

### Claude Code Projects + Dispatch (Anthropic)
- 2026年9月17日、Claude CodeのProjects機能を刷新。複数のAIエージェントをクラウド上で協調動作させる機能を提供。各プロジェクトは共有メモリ・目標・ファイルライブラリを持ち、複数スレッドが並行してタスクを実行。
- 参照: [https://www.theverge.com/ai-artificial-intelligence/997134/anthropic-claude-code-projects](https://www.theverge.com/ai-artificial-intelligence/997134/anthropic-claude-code-projects)

### Jev (System One) (TypeSafe AI)
- 2026年9月中旬発表。文章を生成せず判断のみを返す高速AIモデル。50ms超低遅延を実現。MCP接続、ブラウザ操作、コードレビュー、文脈選別など多様な用途のOSSツールが公開4日で登場。
- 参照: [https://zenn.dev/yukurash/articles/8c286e586afa44](https://zenn.dev/yukurash/articles/8c286e586afa44)

### Meta One (Meta)
- 2026年9月15日グローバル提供開始。Instagram、Facebook、WhatsApp、Meta AIを横断する新サブスクリプション。個人向けは月額949円のCoreと2900円のPremium。AI利用枠の拡大が特徴。
- 参照: [https://www.itmedia.co.jp/news/article/2609/16/2000001529.html](https://www.itmedia.co.jp/news/article/2609/16/2000001529.html)

### Claude Sonnet 4.6 (Anthropic)
- 2026年2月17日発表。コーディング、エージェント機能、長文推論、コンピュータ操作で大幅な性能向上。100万トークンのコンテキストウィンドウをベータ提供。価格は従来のSonnet 4.5と同じ。
- 参照: [https://www.anthropic.com/news/claude-sonnet-4-6](https://www.anthropic.com/news/claude-sonnet-4-6)
